# 健身与运动

`log.csv` 记训练，一行一个动作。

## 列说明

- **日期**：`2026-10-22`
- **部位**：胸 / 背 / 腿 / 肩 / 手臂 / 核心 / 有氧
- **动作**：深蹲、卧推、硬拉……写常见的叫法
- **重量kg**：做组重量，自重动作留空
- **组数** / **次数**：`5` 组 `5` 次
- **时长min**：有氧的时长，力量训练可留空
- **体重kg**：当天体重，一天填一次就够
- **感受**：状态、疼痛、力竭程度

## 记法

一次训练可以写多行（不同动作各一行），也可以一行写完整个训练。看你的习惯。

体重和训练混在一张表里是为了省事，统计时注意：**体重一天只会有一个有效值，别把多行体重加总**。

> 我深蹲重量这三个月怎么变化的
> 这个月练了几次腿
