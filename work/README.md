# 工作与学习

每周一篇复盘，比每天写更容易坚持。

## 文件命名

`work/2026/2026-W43.md`（ISO 周数），或者 `2026-10-第4周.md`，选一种别混用。

## 模板

```markdown
# 2026 第 43 周（10/19 - 10/25）

## 这周做了什么

## 学到的东西
<!-- 写能复述给别人的那种，写不出来说明还没学会 -->

## 卡住的地方
<!-- 这条比上面那条值钱。半年后回看，卡点往往连着同一个根因 -->

## 下周要解决的
```

## 为什么记录「卡住的地方」

「学到了什么」很容易写成流水账。「卡在哪、为什么卡」才是能复用的东西。同一个坑踩第二次的时候，你会感谢自己写过。

## 常问的问题

> 我过去半年反复卡在哪些问题上
> 关于 XX 这个技术，我之前记过什么
