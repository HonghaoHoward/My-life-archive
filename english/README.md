# 英语

`checkin.csv` 每天一行，重点是连续，不是单次时长。

## 列说明

- **日期**：`2026-10-22`
- **类型**：听力 / 口语 / 阅读 / 写作 / 单词 / 语法
- **内容**：具体做了什么，例如「BBC 6 Minute English 两集」
- **时长min**：当天投入分钟数
- **完成**：`TRUE` / `FALSE`
- **备注**：难点、生词、明天的计划

## 记法

一天一行，多种类型可以合并写一条（内容里说明），也可以拆成多行。

## 常问的问题

> 我这个月英语打卡断了几天
> 哪一类练得最少
> 累计投入多少小时了
