# 财务

`ledger.csv` 记所有收支，一张表，不建第二张。

## 列说明

- **日期**：`2026-10-22` 格式
- **收支**：`支出` 或 `收入`
- **类别**：餐饮 / 交通 / 居住 / 购物 / 娱乐 / 医疗 / 学习 / 人情 / 其他
- **项目**：具体买了什么，几个字即可
- **金额**：正数，不要写负号，收支列已经区分了
- **支付方式**：微信 / 支付宝 / 银行卡 / 现金 / 其他
- **备注**：可留空

## 记法

一行一笔，追加到文件末尾。不用每天汇总，也不用分月文件——需要看月度的时候让 AI 汇总就行。

想算「这个月餐饮花了多少」，直接问：

> 看 finance/ledger.csv，算一下 10 月各类别支出占比

## 关于资产

流水记的是"钱怎么花的"。如果你还想记"我有多少钱"（存款、投资、负债），那属于快照，不是流水，建议单独建 `balance.csv`：

```
日期,账户,类型,余额
```

需要的时候再说，先用流水跑起来。
