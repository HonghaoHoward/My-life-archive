# 我的人生档案

把每天的积累，变成看得见的人生轨迹。

这是一个**私有**仓库，只有你自己能看到。日记、财务、训练、学习都放在这里，用 Markdown 和 CSV 存，任何设备、任何 AI 都能读。

---

## 目录结构

```
journal/     每日日记，按年分文件夹
work/        工作与学习：周复盘、踩坑记录
finance/     财务：ledger.csv 记流水
fitness/     健身：log.csv 记训练
english/     英语：checkin.csv 记打卡
interests/   兴趣与收藏：随笔、剪藏、灵感
dashboard/   看板（预留，后续做）
```

## 三种打开方式

**电脑上**
用任何文本编辑器打开这个文件夹（VSCode、Typora、Obsidian 都行）。Markdown 直接改，CSV 用表格软件改。

**手机上**
有两种方式，体验差别很大：

- **网页版**：浏览器打开 github.com，进到文件，右上角铅笔图标就能编辑。能用，但手机上打字排版比较累。
- **Obsidian 手机版 + Obsidian Git 插件**（推荐）：首次配置一次仓库地址和 token，之后打开就是本地笔记，改完自动同步。这是手机上最舒服的方式。

注意：GitHub 官方手机 App **不能编辑文件**，只能看和评论。别指望用它写日记。

**给其他 AI 用**
把仓库地址给它，或者在别的 AI 里配置 GitHub 连接。私有仓库需要它持有你的访问 token，注意只给你信任的工具。

## 记录规矩

**一、数据只追加，不新建文件。**
财务、健身、打卡全部往同一张 CSV 加行。一天建一个新文件，三个月后就没法看趋势了。

**二、日记一天一篇，不合并。**
合并成「10 月总结」之后，具体某天的情绪和细节就找不回来了。

**三、允许空白。**
这套东西是服务你的，不是用来打卡失败的。这周只写了两篇，也比零篇好。

**四、CSV 用 UTF-8 编码。**
用 Excel 打开如果中文乱码，改用「数据 → 从文本/CSV」导入并选 UTF-8，或者直接用文本编辑器。

## 隐私

仓库是私有的，只有你能访问。**千万不要改成公开**——这里面有你的财务和日记。

如果哪天想分享某篇内容，复制出去单独发，别改仓库可见性。
